译幕 — 隐私说明

更新日期：2026 年 9 月 27 日。本说明描述从 GitHub 源码运行的本地预览版。

译幕由 Chrome 扩展和运行在你电脑上的本地服务组成。项目没有由维护者运营的远程后台、分析服务或广告跟踪。中文配音会调用 MiniMax API，并可能产生费用。

处理的数据

  • 有可读字幕：扩展读取当前 YouTube 视频的字幕，将视频链接、时间轴与字幕交给本机服务；本机服务将待翻译文本发给 MiniMax，并将译文发给 MiniMax 合成中文语音。
  • 没有可读字幕：本机服务通过 yt-dlp 读取视频信息并下载音轨，将音频片段发给 MiniMax 识别，再提交识别文字用于翻译和配音。视频读取也可能因 YouTube 限制而失败。
  • 播放：整片处理完成后，本地网页或扩展按视频时间显示中文字幕，并从本机服务读取配音文件播放。

本地保存

从扩展填写的 MiniMax API Key 和界面设置保存在 chrome.storage.local，创建任务时密钥会发送到本机服务，并仅在该服务进程内存中保留；从本地网页填写的密钥也只保留在当前服务进程内存中。本机服务把已读取的字幕、音轨、识别结果、译文和配音文件保存在 local-service/data/，供失败后复用；停止或重启服务不会自动删除这些文件。该目录已被项目的 Git 忽略规则排除。扩展的字幕缓存与部分界面偏好分别存放在浏览器本地存储中。

你可以清除扩展字幕缓存、删除扩展的本地数据，或自行删除 local-service/data/ 中的处理文件。删除缓存后，再次处理同一视频可能重新调用 MiniMax。

第三方服务

当前整片中文配音主流程使用 MiniMax 国内 API。MiniMax 会接收识别所需的音频片段、待翻译文字与待合成的译文；其数据保留、计费和限流以 MiniMax 的说明为准。扩展源码仍保留部分旧服务的权限和代码，未来提交 Chrome 应用商店前会重新审查与精简。若手动开启“使用本机 Chrome 登录状态读取视频”，yt-dlp 会读取 Chrome 的 Cookie；默认不开启，也不会将 Cookie 发给 MiniMax。

浏览器权限

  • activeTab 和 scripting：在你操作的 YouTube 标签页中显示控件和字幕。
  • storage：记住设置、密钥与字幕缓存。
  • 站点访问权限：读取 YouTube 视频与字幕，连接本机服务及当前启用的第三方服务。具体域名见 manifest.json。

你可以在扩展中停止当前任务；本地服务仍会运行，直到你关闭它。重启本地服务会使内存中的任务编号失效，但不会自动清除已保存的处理文件。
